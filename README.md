# WEB-SPRINT

Учебный репозиторий для изучения веб-разработки на React и TypeScript

## Цель

Научиться понимать и самостоятельно писать код начиная с основ.

Конфигурация хранится в переменных окружения, чтобы один и тот же код можно было запускать с разными настройками без изменения исходного кода.
